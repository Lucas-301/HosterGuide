Chapter 01

Resetting an Event

Clear ticking areas and reset the map and event.

  1. Clear Ticking Areas

    Before resetting the event, run:

    /tickingarea remove_all

    All ticking areas must be cleared before continuing.

  2. Reset the Map and Event

    Run:

    -resetui

    When the menu opens, press Submit to reset the map and event interface.

Chapter 02

Configuring and Starting an Event

Set the host settings and start the event.

  1. Configure Host Settings

    Run:

    -host

    In the menu:

    • Find Shrinking Time and enter 1250.
    • Scroll down to Grace Duration and enter 7 (seven minutes).

  2. Start the Event

    Press Submit to apply the settings and start the event.

Chapter 03

Announcing Your Event

Post your event in Discord with the IP and port.

  1. Open Discord

    Open the Royal Events Discord server.

  2. Find the Events Channel

    Open the events channel.

  3. Announce Your Event

    Post a message announcing your event. Include the IP and port.
